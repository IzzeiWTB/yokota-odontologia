README - Yokota Odontologia (landing)

Esta landing já usa imagens baixadas do site original. O scraper `scrape_sites.py` grava assets em `site-1/assets/images` e `site-1/assets/videos`.

Como rodar localmente:

1. Abra o diretório `site-1` no terminal.
2. Rode: `python -m http.server 8001`
3. Abra http://localhost:8001

Os arquivos de imagem do site original estão em `assets/images`. Atualize `index.html` caso queira trocar outras imagens.
